# Governance (Draft)

This is an experimental community fixture corpus. Maintainers review changes for scope, clarity, safety, and reproducibility.

- No fixture implies a real system is affected.
- No fixture is a certification or security verdict.
- Changes should include provenance, expected behavior, and limitations.
- Material format changes should be discussed before merging.
- Disagreements should be recorded in review notes rather than hidden.

This document does not establish a formal standards body or certification process.
